umination

効かせるための足し算をしない、軽量スクロールアニメーションライブラリ。GSAP 非依存、data 属性なし。

01 / Getting Started
使い方

① script を読み込む

HTML 
<script type="module" src="/dist/umination.js"></script>

② effect class を付けるだけ — スクロールで自動発火

HTML 
<h2 class="umn-slide-up">Heading</h2>
<p class="umn-fade-in umn-delay-200">Text</p>
<img class="umn-scale-in" src="image.jpg" alt="">

npm でも使えます

Shell 
npm install @umi-design/umination
JavaScript 
import { initUmination } from '@umi-design/umination';
initUmination();

06 / umn-repeat
Repeat

デフォルトは一度表示したら戻らない。umn-repeat を付けると、画面の出入りのたびに表示・非表示が切り替わる。

下の枠を何度もスクロールで出し入れして確認してください（Replay 不要・自動で反応します）。

スクロールで出入りするたびに表示・非表示が切り替わる

08 / CSS Variables
style 属性で個別カスタマイズ

大きな distance ＋ 長い duration

--umn-distance: 60px; --umn-duration: 1.2s;

強いブラー ＋ 遅れて登場

--umn-blur: 24px; --umn-duration: 1.6s; --umn-delay: 0.3s;

大きくスケールアップ

--umn-scale: 0.8; --umn-duration: 1s;

CSS Variables 一覧 
:root {
  --umn-duration:            0.8s;
  --umn-delay:                0s;
  --umn-stagger-step:        0.1s;
  --umn-distance:            24px;
  --umn-blur:                12px;
  --umn-scale:               0.88;
  --umn-ease:                cubic-bezier(0.22, 1, 0.36, 1);
  --umn-hover-shadow:        0 8px 24px rgba(0, 0, 0, 0.15);
  --umn-hover-lift-distance: -4px;
  --umn-hover-border-color:  currentColor;
  --umn-hover-tilt-deg:      -2deg;
  --umn-hover-opacity:       0.7;
}
09 / window.Umination
JS API
JavaScript 
window.Umination.init()     // 初期化（html に umn-ready を付与、対象要素を監視開始）
window.Umination.refresh()  // 後から追加された要素を再スキャン（後方互換。通常は不要）
window.Umination.destroy()  // observer を解除・内部状態リセット

init() 実行時、MutationObserver による動的要素の自動検知もデフォルトで有効になる。refresh() を手動で呼ばなくても、後から追加された要素は自動でアニメーション対象に加わる。

ES Module

JavaScript 
import { initUmination, refreshUmination, destroyUmination, UMINATION_EFFECT_CLASSES } from '@umi-design/umination'
