umination

class 1つ + script 1ファイル。
軽量スクロールアニメーションライブラリ。

Getting Started
使い方

① script を読み込む

HTML 
<script type="module" src="/dist/umination.js"></script>

② effect class を付けるだけ — スクロールで自動発火

HTML 
<h2 class="umn-slide-up">Heading</h2>
<p class="umn-fade-in umn-delay-200">Text</p>
<img class="umn-scale-in" src="image.jpg" alt="">

npm でも使えます

Shell 
npm install @umi-design/umination
JavaScript 
import { initUmination } from '@umi-design/umination';
initUmination();
Effect classes
エフェクト一覧
umn-fade-in フェードイン
umn-slide-up 下から上へ
umn-slide-down 上から下へ
umn-slide-left 右から左へ
umn-slide-right 左から右へ
umn-blur-in ブラーから鮮明に
umn-scale-in スケールアップ
umn-scale-in + umn-img-zoom
Image — scroll & hover

スクロールで進入 → hover でズーム。2クラスを組み合わせるだけ。

HTML 
<div class="umn-scale-in umn-img-zoom">
  <img src="photo.jpg" alt="">
</div>
umn-img-zoom
Image zoom — hover

コンテナに付けると、hover で内側の img が scale(1.05) にズーム。JS 不要。

HTML — コンテナに付けるだけ 
<div class="umn-img-zoom">
  <img src="photo.jpg" alt="">
</div>

<!-- <a> でも使えます -->
<a class="umn-img-zoom" href="...">
  <img src="photo.jpg" alt="">
</a>

CSS Variables
style 属性で個別カスタマイズ

大きな distance ＋ 長い duration

--umn-distance: 60px; --umn-duration: 1.2s;

強いブラー ＋ 遅れて登場

--umn-blur: 24px; --umn-duration: 1.6s; --umn-delay: 0.3s;

大きくスケールアップ

--umn-scale: 0.8; --umn-duration: 1s;

CSS Variables 一覧 
:root {
  --umn-duration: 0.8s;
  --umn-delay:    0s;
  --umn-distance: 24px;
  --umn-blur:     12px;
  --umn-scale:    0.96;
  --umn-ease:     cubic-bezier(0.22, 1, 0.36, 1);
}
